
# SpendWise - Budget Tracker

## Project Description
SpendWise is a simple budget tracking application that helps users manage their monthly budget, record expenses, calculate total spending, and monitor their remaining balance.

## JavaScript Concepts Implemented

- Variables
- Data types
- User input using prompt()
- Arithmetic calculations
- Functions
- Conditional statements
- Loops
- Arrays and objects
- Console output

## How Variables Are Used
Variables store the monthly budget, expenses, expense names, total expenses, and remaining balance.

## How User Input Is Collected
The prompt() function collects the monthly budget, number of expenses, expense names, and expense amounts.

## How Calculations Are Performed
The application adds all expenses to calculate total spending.

Remaining Balance = Monthly Budget - Total Expenses.

## Functions
Two reusable functions are used:

1. calculateTotalExpenses() - Calculates total expenses.
2. calculateRemainingBalance() - Calculates the remaining budget.

Functions organize the code and make it easier to maintain.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open index.html in a browser.
2. Enter your monthly budget.
3. Enter your expenses.
4. View the calculated results on the dashboard.
5. Open the browser console to see the budget report.
